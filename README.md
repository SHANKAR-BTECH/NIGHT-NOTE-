# NightNote 🌙

NightNote is an AI-powered evening thought recorder and morning focus optimizer. It converts night brain dumps into actionable, prioritized morning missions using Groq Llama-3.3-70B.

## Features
- **Voice Thought Capture**: Capture night thoughts using Native Android Speech Recognition or browser Web Speech.
- **AI Focus Mission Generator**: Convert raw night notes into 3–6 actionable tasks with assigned priorities and durations.
- **Smart Workload Trim**: Optimize today's mission using Groq AI or local workload balancing to prevent burnout.
- **Progress Tracking & AI Weekly Summary**: Monitor focus consistency, complete daily missions, and receive weekly AI productivity summaries.
- **Dark Mode & Calming Themes**: Eye-safe, calming twilight UI for night capture and clean light mode for day focus.

## Tech Stack & Native Setup
- React 18, Vite, TypeScript, Tailwind CSS
- Capacitor 6+ with `@capacitor-community/speech-recognition`
- Groq Llama 3.3 70B API integration
- LocalStorage persistence with full offline support
